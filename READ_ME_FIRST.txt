MB1 PRICING FAILSAFE v3

THIS VERSION DOES NOT USE A PRICE LOOKUP TABLE.

The displayed price is read directly from the customer's selected size option.

Expected examples:
8"  — $49  -> $49
12" — $69  -> $69
18" — $109 -> $109
24" — $149 -> $149
30" — $195 -> $195
36" — $265 -> $265
48" — $349 -> $349

The word "undefined" cannot be displayed by this pricing function.
If a price is ever missing, the page simply shows the normal
Customize / Request Quote button without an undefined price.
