HOW TO UPDATE

1. Open this ZIP.
2. Copy index.html and all 12 category .html files.
3. Paste them into your existing local mb1-catalog folder.
4. Choose Replace All.
5. Open GitHub Desktop.
6. Leave the changed HTML files checked.
7. Uncheck .DS_Store if it appears.
8. Summary: Install simple pricing v4
9. Click Commit to main.
10. Click Push origin.
